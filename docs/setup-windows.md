# Phase 1 の準備 — Windows

Phase 0（GitHubで公開）が終わってから読んでください。
ここでは Python と Claude Code を入れます。所要 20〜30分。

Phase 1 以降は「スクリプトを走らせる → 落ちた年を直す → また走らせる」の反復になります。
この反復をGitHub上でやると1回4〜5分待つことになるので、手元で動かせるようにします。

---

## ステップ0 — フォルダを置いて Claude Code を開く（10分）

### フォルダを置く

1. エクスプローラー → 左の「ダウンロード」から `okinawa-atlas` を探す
   （zipなら右クリック → すべて展開）
2. 「ドキュメント」にドラッグして移動する。最終形は
   `C:\Users\（あなた）\Documents\okinawa-atlas`
3. フォルダを開いて **`README.md` が見えるか確認する**

`okinawa-atlas` の中にもう1つ `okinawa-atlas` がある場合は、内側を開いて
全選択（Ctrl+A）→ 切り取り（Ctrl+X）→ 1つ上に貼り付け（Ctrl+V）で解消します。
二重になっていると以降すべて失敗します。

### そのフォルダで Claude Code を開く

`cd` を覚える必要はありません。アドレスバーを使います。

1. `okinawa-atlas` フォルダを開く（`README.md` が見えている状態）
2. 上部のアドレスバー（`> ドキュメント > okinawa-atlas` の帯）をクリック
3. パスが選択された状態で `powershell` と打って Enter
4. 開いたウィンドウのパスが `...\okinawa-atlas>` になっていることを確認
5. `claude` と打って Enter

この方法ならフォルダを間違える余地がありません。

### 複数の案件を並行して動かす場合

Claude Code は起動したフォルダを作業範囲にするので、フォルダが別なら案件は独立します。
`CLAUDE.md` も起動したフォルダのものが読まれます。同時に走らせても構いません
（利用上限は共有されるので消費は増えます）。

危ないのは**複数の案件を含む親フォルダで起動してしまうこと**です。
`Documents` やユーザーフォルダそのもので起動すると、別案件のファイルまで
編集できる状態になります。

**毎回セッションの最初にこれを打つ習慣をつけてください。**

```
いまどのフォルダで動いていますか。パスを教えてください。
```

`...\Documents\okinawa-atlas` なら安全です。`...\Documents` だけだったら
そのセッションを閉じて、アドレスバーの方法でやり直してください。

## 先に確認 — プランの条件

**Claude Code は Pro / Max / Team / Enterprise のいずれかのプランが必要です。
無料プランには含まれていません。**

いま無料プランなら、ここで Pro に切り替えるか判断が必要です。判断材料として、
Phase 1〜5 で Claude Code を使わない場合の代替は「私（claude.ai のチャット）に
エラーを毎回貼り付けて、直したファイルをもらって差し替える」という進め方になります。
動きますが、15ファイルぶんの試行錯誤だとやり取りが数十往復になります。

プラン状況は左下のアカウントメニューから確認できます。

## ステップ1 — Python を入れる（10分）

1. <https://www.python.org/downloads/windows/> を開く
2. **Python 3.13** または **3.12** の「Windows installer (64-bit)」をダウンロード
   （最新版が3.14以降になっている場合も、pandas等の対応を待つため3.13を選ぶのが無難です）
3. ダウンロードした `.exe` をダブルクリック
4. **最初の画面で「Add python.exe to PATH」のチェックを入れる**

   > **ここが最重要です。** このチェックを忘れると、後で「python は認識されていません」
   > というエラーになります。忘れた場合はインストーラをもう一度実行して
   > 「Modify」から入れ直せます。

5. **Install Now** を押す
6. 終わったら **Disable path length limit** というボタンが出ることがあります。出たら押してください

### 確認

スタートメニューで `powershell` と入力して **Windows PowerShell** を開き、次を打ちます。

```powershell
py --version
```

`Python 3.13.x` のように出れば成功です。`py` が認識されない場合は PATH のチェックを
忘れているので、ステップ1-4に戻ってください。

続けて、このプロジェクトで使うライブラリを入れます。

```powershell
py -m pip install openpyxl pandas xlrd
```

最後に `Successfully installed ...` と出れば完了です。

## ステップ2 — 手元でスクリプトが動くか確かめる（5分）

PowerShell で、Phase 0 で置いたフォルダに移動します。

```powershell
cd $HOME\Documents\okinawa-atlas
py scripts\parse_survey.py data\raw\survey\latest.xlsx
```

`--- counts ---` に続いて `"municipalities": 41` と出れば、手元の環境が整いました。

```powershell
py scripts\build_app.py
```

`wrote public\index.html` と出れば、ビルドも手元でできる状態です。
`public\index.html` をダブルクリックすると、公開サイトと同じものがブラウザで開きます。

## ステップ3 — Claude Code を入れる（10分）

> **すでに Claude Code を使っているならこのステップは不要です。** ステップ4へ進んでください。

ターミナルを使わない方法と使う方法があります。**初めてならデスクトップアプリを勧めます。**

### 方法A — デスクトップアプリ（画面操作、推奨）

1. <https://claude.com/download> を開いて Windows 版をダウンロード
2. インストールして起動、いつものアカウントでサインイン
3. 左側の **Code** タブを開く
4. **Add folder**（またはフォルダを開く操作）で `Documents\okinawa-atlas` を選ぶ

これでチャット欄に指示を打てば、Claudeがフォルダのファイルを直接読み書きします。
`/model` などのコマンドもこの入力欄で使えます。

### 方法B — PowerShell（ターミナル）

PowerShell を開いて次の1行を貼ります。管理者権限は不要です。

```powershell
irm https://claude.ai/install.ps1 | iex
```

終わったら **PowerShellを一度閉じて開き直します**（PATHの変更が反映されるのは新しいウィンドウからです）。
そのあと確認します。

```powershell
claude --version
```

バージョン番号が出たら、プロジェクトフォルダで起動します。

```powershell
cd $HOME\Documents\okinawa-atlas
claude
```

初回はブラウザが開いてサインインを求められます。許可すれば完了です。

## ステップ4 — CLAUDE.md が読まれているか確認する（2分）

Claude Code を起動したら、最初にこれだけ打ってください。

```
CLAUDE.md を読んで、このプロジェクトで守るべきルールを3つ挙げてください。
```

「人口の数値を推測で作らない」「サンプル値は視覚的に区別する」「0と回答なしを混同しない」
といった趣旨が返ってくれば、プロジェクトの指示が正しく読み込まれています。

**別案件の話が返ってきた場合は、フォルダを間違えています。** セッションを閉じて、
ステップ0のアドレスバーの方法でやり直してください。的外れな答えの場合も同様で、
`okinawa-atlas` フォルダ自体を指定しているか（その親フォルダや中の `scripts` を
指定していないか）を確認します。

確認できたら `docs/handoff.md` の Phase 1 に進みます。

## Windows でよくつまずく点

| 症状 | 原因 | 対処 |
|---|---|---|
| `python は認識されていません` | PATHのチェック忘れ | インストーラを再実行 → Modify → Add to PATH |
| `トークン '&&' は有効な...ではありません` | CMD用のコマンドをPowerShellで実行した | `&&` を使わず1行ずつ実行する |
| `claude` が見つからない | インストール後にターミナルを開き直していない | PowerShellを閉じて開き直す |
| インストーラで青い警告画面が出る | Windows の SmartScreen | 「詳細情報」→「実行」。公式サイトから落としたものなら問題ありません |
| `py` は動くが `python` は動かない | Windows標準の挙動 | `py` を使ってください。本手順書はすべて `py` で書いています |

## 迷ったときの原則

エラーメッセージは読まずに、**そのまま私に貼ってください。**
PowerShell の文字は、範囲を選択して右クリックでコピーできます。

自分で解読しようとして設定をいじると、原因が増えて切り分けが難しくなります。
「貼って聞く」が最短です。
