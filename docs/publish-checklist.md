# 公開前チェックリスト

技術的な知識なしで実施できます。毎年、調査Excelを差し替えて公開する前に一度通してください。
所要 15〜20分。

Claudeに「チェックリストを通して」と頼まず、**自分の目で見てください。**
ここは委任してしまうと、間違いを見つける最後の関門がなくなります。

---

## 1. 公開して問題ないファイルだけか（5分）

GitHubのリポジトリ画面を開いて、フォルダを上から順にクリックして中身を見ます。

- [ ] ヒアリングのメモ、議事録、名刺情報、連絡先一覧が混ざっていない
- [ ] `data/raw/` にあるのは県・国の公開データと調査Excelだけ
- [ ] 調査Excelの中に、公開を前提としていない担当者の個人携帯番号などが入っていない

> 調査票には自治体担当者や中間支援組織の氏名・部署・電話番号が入っています。これらは
> 業務上の公開連絡先なので、原則そのまま公開して問題ありません。
> 令和7年度分は確認済みです（携帯番号形式の記載が1件ありますが、公開されている
> 事業者連絡先であることを確認しています）。
>
> 新年度分では、新しく追加された記述欄に**公開を前提としていない連絡先**が
> 混ざっていないかだけ確認してください。検出のしかたは下の「機械的に洗い出す」を参照。

一度プッシュしたファイルは、あとで消しても履歴から辿れます。**入れる前に見るのが唯一の対策です。**

### 機械的に洗い出す

目視だけだと見落とすので、Claude Code に次を頼んでから目視してください。

```
data/raw と data/generated の全ファイルを検索して、携帯電話番号の形式
（090/080/070 で始まる11桁）とメールアドレスが含まれる箇所を一覧にしてください。
削除や変更はせず、一覧だけ出してください。公開可否の判断は私がします。
```

出てきた一覧のうち、前年から増えた行だけを見れば足ります。

## 2. 数字を1つ、手で検算する（5分）

これが一番重要です。ETLが壊れていても画面は正常に見えます。

- [ ] 公開サイトで市町村を1つ開く（毎年違う市町村を選ぶ）
- [ ] 元の調査Excelの同じ市町村の行を開く
- [ ] 「推定空家数」「市町村営住宅の空き住戸」「定住促進住宅の件数」の3つが一致する
- [ ] 選択式のバッジ（空家等対策計画、空き家バンクなど）が、Excelの回答と一致する

1つでもずれていたら、他も疑ってください。ずれた内容をそのままClaudeに伝えれば原因を追えます。

字別人口を入れたあとは、これも追加します。

- [ ] ある市町村の字の人口を全部足した値が、県の住基人口（市町村計）とおおむね一致する
- [ ] 一致しない場合、その差が「名寄せできていない字」の分で説明できる

## 3. 「回答なし」と「0」が混ざっていないか（3分）

- [ ] 花ブロックが白い市町村を1つ選び、画面に「回答なし」と出ている
- [ ] Excelでその市町村の該当欄が実際に空欄である（0と書かれていない）
- [ ] 指標の凡例に、白＝回答なしである説明が出ている

推定空家数は41市町村中16件しか数値がありません。**25市町村が「0件」に見えていたら、それは誤りです。**

---

## 4. 出典と基準年が画面に出ているか（3分）

- [ ] 各グラフに出典年が書かれている
- [ ] 令和2年国勢調査の値が「最新」と誤読されない表記になっている
- [ ] 字の人口推移に、平成25年以前と平成26年以降で基準日が違う（3月31日／1月1日）注記がある
- [ ] サンプル値がまだ残っている箇所に、斜線と「ダミー」タグが出ている

**斜線が消えているのに実データが入っていない、という状態が最悪です。** 実データを入れた
フェーズの直後は、必ずここを見てください。

## 5. 未確認回答の扱い（2分）

- [ ] 「最終確認状況」がFALSEの市町村に、画面上で「未確認」と表示されている
- [ ] 今年のExcelでFALSEになっている市町村の一覧を確認した

令和7年度分は 糸満市・豊見城市・宜野座村・北谷町・北中城村・西原町 の6件です。
年によって変わるので、`data/generated/quality_report.json` の `unconfirmed_policy` を見てください。

## 6. 品質レポートを見る（2分）

GitHubの Actions タブで最新の実行を開くと、実行サマリにデータ品質の要約が出ます。

- [ ] `code_join_failures` が 0 件
- [ ] `needs_manual_review` の件数が、前回より不自然に増えていない
- [ ] `municipalities` が 41

`code_join_failures` が1件でもあると、その市町村のデータが画面に出ていません。
静かに欠落するので、この数字だけは毎回見てください。

## 通らなかったとき

チェックに引っかかった項目を、そのままClaudeに伝えてください。
**公開を止めるかどうかは自分で決めてください。** 「軽微だから出してよい」の判断は、
御社の名前でデータを出す立場の人がするものです。
